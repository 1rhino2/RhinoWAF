Self-Hosted Web Application Firewall

A Go WAF you run on your own VPS in front of nginx, Caddy or Traefik. Rate limiting, bot challenges, and a detection engine that explains every block.

Quick start Download

What it does

Detection engine

Its own rule engine with anomaly scoring. A SQL tokenizer and an HTML-aware XSS check instead of banned substrings, so "grant writing tips" passes and "' or 1=1--" does not.

Explains itself

Every block logs which rule hit, on which argument, and the matched bytes. Detect mode lets you watch a new site before you enforce.

DDoS and bots

Per-IP rate limits, Slowloris protection, JavaScript, proof-of-work, hCaptcha and Turnstile challenges, browser fingerprinting.

Survives restarts

Auto-bans and solved challenges are persisted, so a restart does not forget who was banned or make everyone re-solve a challenge.

IP and geo rules

Bans, whitelists, geo and ASN rules in JSON, hot-reloaded while running. IPv6 throughout.

Single binary

No dependencies at runtime. Default rules are built in, so it works with no config and you tune from there.
